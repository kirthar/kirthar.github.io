Política de privacidad

Finance · Última actualización: 5 de noviembre de 2026

Finance es una aplicación personal, autoalojada y de uso privado, creada para que su titular consulte y organice sus propias cuentas bancarias. No está dirigida al público ni se ofrece como servicio a terceros.

1. Responsable del tratamiento

El responsable es el titular del sitio chris.cat, que es también el único usuario de la aplicación y el titular de las cuentas conectadas.

2. Datos que se tratan

  • Saldos y movimientos de las cuentas bancarias que el propio titular autoriza.
  • Identificadores de las cuentas (IBAN, nombre de la cuenta) y datos técnicos de la conexión bancaria.
  • Categorías, reglas y presupuestos que el titular define dentro de la aplicación.

3. Finalidad y base jurídica

Los datos se usan únicamente para la gestión de las finanzas personales del titular (consulta, categorización y presupuestos). La base es el consentimiento del propio titular, que autoriza el acceso a su banco.

4. Cómo se obtienen los datos

El acceso a las cuentas se realiza mediante el servicio de información de cuentas (AIS) de la directiva europea PSD2, a través del proveedor Enable Banking. El acceso es de solo lectura: la aplicación no puede iniciar pagos ni mover dinero. El titular puede revocar el consentimiento en cualquier momento desde su banco o desde la propia aplicación.

5. Almacenamiento y seguridad

Los datos se guardan en una base de datos local bajo el control exclusivo del titular. Los tokens de acceso se almacenan cifrados. La aplicación no es accesible públicamente: solo se expone el punto de retorno técnico necesario para completar la autorización bancaria.

6. Comunicación a terceros

Los datos no se venden, no se ceden ni se comparten con terceros, ni se usan para publicidad o perfilado. El único tercero implicado es el proveedor de acceso bancario (Enable Banking) y el propio banco, necesarios para obtener la información.

7. Conservación

Los datos se conservan mientras el titular use la aplicación. Puede borrarlos en cualquier momento eliminando la conexión bancaria o la base de datos local.

8. Derechos

Como titular y único usuario, puedes acceder, rectificar, suprimir o limitar el tratamiento de tus datos directamente en la aplicación. Si tienes cualquier consulta, puedes contactar con el titular del sitio chris.cat.

9. Cambios

Esta política puede actualizarse; la fecha de la última revisión figura al inicio.
